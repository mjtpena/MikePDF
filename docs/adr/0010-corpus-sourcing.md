# ADR-0010: Corpus sourcing and storage
- Status: Proposed
- Date: 2026-10-27
- Deciders: Opus (approver), Opus (proposer). Storage budget: User

## Context
§12.2 calls for a manifest-driven corpus in three tiers: smoke (~200 files, every PR), core (~5,000, nightly) and full (50,000+, weekly). Every file needs its source, licence and hash recorded, and files whose licences forbid redistribution must never be committed. ADR-0003 governs which licences are acceptable.

## Decision

**1. The manifest is the source of truth.** `corpus/manifest.json` is committed and holds one record per file:
```json
{ "id": "pdfium/embedder_tests/annotation_stamp_with_ap.pdf",
  "source": "https://pdfium.googlesource.com/pdfium/+/refs/heads/chromium/8125/testing/resources/...",
  "licence": "BSD-3-Clause", "redistributable": true,
  "sha256": "…", "bytes": 101719,
  "tags": ["annot:stamp", "ap:present"], "tiers": ["smoke", "core", "full"],
  "expect": { "opens": true, "password": null, "pages": 1 } }
```
`expect` lets the gates in §0.3 and §17 tell "failed to open" apart from "expected to fail", which matters for hostile files.

**2. Storage**
- Redistributable files go in a release-asset or blob bundle per tier, addressed by content hash.
- Non-redistributable files go only in **private blob storage**, fetched in CI with a scoped credential. This needs the user's budget (R-25).
- No PDF bytes are committed in the repo, except fixtures that MikePDF's own tests generate and that are under 100 KB.

**3. Fetching.** `corpus/fetch.ps1 -Tier smoke|core|full` downloads, checks hashes, and fails if a hash doesn't match.

**4. Source evaluation.** No source enters a tier until its licence status is VERIFIED.

| Source | Licence status | Notes |
|---|---|---|
| PDFium `testing/resources` | **VERIFIED**: BSD-3-Clause (PDFium licence shipped with the binaries) | 343 PDFs at chromium/8125. Already used by M0 spikes (`spikes/_shared/corpus/fetch.ps1`) |
| pdf.js `test/pdfs` | UNVERIFIED for each file | The repo is Apache-2.0, but many test PDFs are fetched from external URLs under their own terms |
| veraPDF corpus / Isartor | UNVERIFIED | PDF/A focus. Matters most for P2 |
| Arlington PDF Model | UNVERIFIED | Used as a validator, not a corpus |
| GovDocs1 (Digital Corpora) | UNVERIFIED | Real-world breadth. Check the redistribution terms |
| SafeDocs / Common Crawl PDFs | UNVERIFIED | Large-scale breadth for the full tier |
| "Nasty" set (§12.2) | Generated by MikePDF tooling where possible | Generated files are MikePDF-owned. Third-party crash files need licence checks |
| Business set (§12.2) | Public-domain government forms (e.g. ATO and US IRS forms) | Check each form's terms. Never real personal documents |

**5. Privacy.** No corpus file may contain real personal data. Business-set fixtures are synthetic or published blank forms.

## Consequences
- M1 builds the manifest tooling and the smoke tier from PDFium resources, plus generated fixtures (including those from S4 and S8).
- Licence verification of the other sources is an M1 task, assigned to Sonnet and reviewed by Opus.

## Verification
- `fetch.ps1 -Tier smoke` passes in CI with every hash matching.
- A CI check rejects manifest entries with `licence` UNVERIFIED in any tier.
