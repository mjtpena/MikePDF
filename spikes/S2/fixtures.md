# S2 fixture corpus

All files live in `spikes/S2/out/fixtures/` (gitignored). Regenerate with `fixtures/FixtureGen` (`dotnet run -c Release --project fixtures/FixtureGen -- out/fixtures out/dl/jpx`), `fixtures/mkjpx.py`, `fixtures/mkjbig2.py`, and the downloads below. Downloads were kept in `spikes/S2/out/dl/<name>/` (one directory per download) and copied into `out/fixtures/` unchanged. Python helpers were run with `python -I`.

Licence column: "generated" = produced by code in this repo, no third-party content. "US gov" = a work of the US federal government (17 U.S.C. section 105), which is public domain in the US; I did not check each embedded third-party item (photos, logos) inside the documents, so **confirm before any of these goes into the real corpus (ADR-0010)**.
